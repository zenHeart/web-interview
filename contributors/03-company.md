# 公司面试指南模版

本文档定义了如何在公司目录下组织和撰写特定公司的面试流程与面试题内容，帮助面试者了解各公司面试特点，同时为面试官提供结构化的面试指导。

## 目录结构规范

每个公司的内容应按以下结构组织：

```
company/
└── <company_name>/
    ├── README.md              # 公司面试概览
    ├── interview-process.md   # 详细面试流程
    ├── technical-focus.md     # 技术考察重点
    ├── question-bank/         # 公司特色题库
    │   ├── basic.md           # 基础题目集
    │   ├── advanced.md        # 进阶题目集
    │   └── project.md         # 项目设计题
    └── experience/            # 面经分享(可选)
        ├── campus.md          # 校招面经
        └── social.md          # 社招面经
```

## 题库组织模板 {#question-bank}

公司特色题目应按以下格式组织：

```markdown

## 题目总览
以下题目来源于[真实面试/牛客网/内部整理...]，按考察频率排序。

## [题目类别1，如JavaScript基础]

### 1. [题目标题]

**基本信息**:
- 难度: [初级/中级/高级]
- 考察频率: [高/中/低]
- 适用岗位: [所有前端/高级前端/...]
- 考察重点: [具体考察的知识点]

**题目描述**:
[清晰描述题目内容]

**标准答案**:
[公司期望的标准答案要点]

**解析**:
[答案的深入解释和扩展]

**相关考察点**:
- [关联知识点1] → [简短说明关联性]
- [关联知识点2] → [简短说明关联性]

**面试官追问**:
1. [追问1] → [期望回答]
2. [追问2] → [期望回答]

### 2. [题目标题]
[类似结构]

## [题目类别2，如框架原理]
[类似结构]
```
