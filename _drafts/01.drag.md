# 拖曳实现

## 核心原理概述

这个 tab 拖拽实现基于 HTML5 的 Drag and Drop API，通过监听拖拽事件来实现 tab 位置重排。

## 关键组件分析

### 1. 状态管理

```javascript
const draging = null // 记录正在拖拽的tab索引
const dragHold = ref(null) // 记录拖拽悬停的目标位置索引
```

### 2. 核心函数 `findNode`

```javascript
const findNode = event => {
  let index = -1
  for (let i = 0; i < tabContent.value.children.length; i++) {
    if (tabContent.value.children.item(i) === event.target.closest('.tab-item')) {
      index = i
      break
    }
  }
  return index
}
```

**作用：** 通过 DOM 遍历找到当前操作的 tab 在 tabList 中的索引位置。

### 3. 拖拽事件流程

#### **开始拖拽 - `onDragStart`**

```javascript
const onDragStart = event => {
  draging = findNode(event) // 记录被拖拽tab的原始位置
}
```

#### **拖拽悬停 - `onDragOver`**

```javascript
const onDragOver = event => {
  event.preventDefault() // 阻止默认行为，允许drop
}
```

#### **进入目标区域 - `onDragEnter`**

```javascript
const onDragEnter = event => {
  const tabItem = event.target.closest('.tab-item')
  if (tabItem) {
    const activeIndex = findNode(event)
    if (activeIndex !== -1) {
      dragHold.value = activeIndex // 标记目标位置
    }
  }
}
```

#### **离开目标区域 - `onDragLeave`**

```javascript
const onDragLeave = event => {
  const tabItem = event.target.closest('.tab-item')
  if (tabItem &&
      !tabItem.contains(event.relatedTarget) &&
      event.target.closest('.isDragHold')) {
    dragHold.value = null // 清除目标位置标记
  }
}
```

#### **放置完成 - `onDrop`**

```javascript
const onDrop = event => {
  event.preventDefault()
  const newArr = [...tabList.value] // 复制原数组
  const temp = newArr.splice(draging, 1) // 移除被拖拽的tab
  newArr.splice(dragHold.value, 0, ...temp) // 插入到目标位置
  tabList.value = newArr // 更新数组
  dragHold.value = null // 重置状态

  // 同步到主进程
  window.csBridge.ipcRenderer.send(
    'tabs',
    window.csBridge.CONTROL_TAB.SORT,
    JSON.parse(JSON.stringify(tabList.value))
  )
}
```

## 核心原理总结

1. **位置跟踪：** 通过 DOM 遍历精确定位 tab 在数组中的索引
2. **状态记录：** 使用 `draging` 记录源位置，`dragHold` 记录目标位置
3. **数组重排：** 使用 `splice` 方法实现数组元素的移除和插入
4. **视觉反馈：** `dragHold` 状态可用于 CSS 样式，提供拖拽时的视觉提示
5. **数据同步：** 通过 IPC 通信将新的 tab 顺序同步到 Electron 主进程

这种实现方式的优势是逻辑清晰，通过原生 HTML5 API 实现，性能良好，并且能够很好地与 Vue 的响应式系统集成。
