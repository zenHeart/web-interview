# 关于简历

## 简历命名

* `应聘岗位+姓名+电话` 的方式
* 采用 pdf
* 倒 L 型，从左至右，从上到下。
* 超强技能点描述举例

```
读了 APUE，实现了一个简单的 Shell，支持重定向和管道。代码在 xxx
```

## 简历模板

- [DIYgod 个人简历范例](https://github.com/DIYgod/Resume)
- [开源 Markdown 简历模板示例（geekcompany）](https://github.com/geekcompany/ResumeSample/blob/master/c.md)

## 技巧

1. 投递时间上班早 8：00
2. web 简历可以是彩色
3. 投入你的诚意，比如打印简历等。
