## 一致性哈希

* 解决分布式缓存的扩展性问题
* 环形哈希空间
* 虚拟节点
* 应用：分布式缓存、负载均衡

## HashMap的并发问题

* 并发问题：
  * 死循环（JDK1.7中的并发扩容问题）
  * 数据丢失
  * 数据覆盖
* 解决方案：
  * 使用Collections.synchronizedMap()
  * 使用ConcurrentHashMap
  * 使用HashTable（不推荐，性能差）
