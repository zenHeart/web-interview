// 实现链表类，支持如下核心方法
// 节点
interface Node {
  value: number
  next: Node | null
}
// 链表
abstract class LinkedList {
  constructor(values: number[]): LinkedList // 构造函数，接收一个数组作为参数，将数组转换为链表

  deleteValues(values: any[]):void // 批量删除，删除值在 values 数组中的节点

}

## 判断单向链表是否是循环链表 {#p0-cycle-check}

```js
function isCyclicLinkedList (head) {
  if (!head) {
    return false
  }

  let slow = head
  let fast = head

  while (fast && fast.next) {
    slow = slow.next
    fast = fast.next.next

    if (slow === fast) {
      return true
    }
  }

  return false
}
```

## 跳表的原理和应用

* 原理：
  * 多层链表结构
  * 每层是下层的子集
  * 类似二分查找的思想

* 应用：
  * Redis的有序集合
  * 替代平衡树的场景
* 时间复杂度：平均O(logN)
