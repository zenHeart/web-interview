## 路径规划 {#p0-unique-paths}

<Answer>

**核心概念**
LeetCode 第 62 题（不同路径 / Unique Paths）：
机器人位于一个 $m \times n$ 网格的左上角 $(0, 0)$，每次只能向右或向下移动一步，求到达右下角 $(m-1, n-1)$ 共有多少条不同的路径：
1. **状态定义**：设 $dp[i][j]$ 表示到达网格 $(i, j)$ 位置的不同路径数。
2. **状态转移方程**：由于只能从上方或左方到达该格，故 $dp[i][j] = dp[i - 1][j] + dp[i][j - 1]$。
3. **边界条件**：第一行与第一列的任意格子都只有 1 种走法（一直向右或一直向下），即 $dp[0][j] = 1, dp[i][0] = 1$。
4. **空间优化（滚动数组）**：$dp[j]$ 仅依赖本行的左侧值和上一行的同列值，可用长度为 $n$ 的一维数组完成状态压缩。

**代码实现（一维滚动数组最优解）：**

```javascript
function uniquePaths (m, n) {
  // 初始化一维 dp 数组，首行所有格子路径数均为 1
  const dp = new Array(n).fill(1)

  for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
      // 当前格子路径 = 原上一行同列值(dp[j]) + 本行左侧值(dp[j-1])
      dp[j] = dp[j] + dp[j - 1]
    }
  }

  return dp[n - 1]
}

// 验证
console.log(uniquePaths(3, 7)) // 28
console.log(uniquePaths(3, 2)) // 3
```

**复杂度分析**
- 时间复杂度：$O(m \times n)$，双重循环遍历网格。
- 空间复杂度：$O(n)$，仅需一行长度为 $n$ 的数组空间。

**面试官视角**
- 考查从基础的二维矩阵 DP 推导，下探到空间压缩降维（一维滚动数组）的能力；数学背景好的候选人还可指出利用组合数学公式 `C(m+n-2, m-1) = (m+n-2)! / ((m-1)!(n-1)!)` 直接在 $O(\min(m, n))$ 时间内计算完成。

</Answer>

## [200. 岛屿数量](https://leetcode.cn/problems/number-of-islands/)**

* 难度：中等
* 考点：DFS、BFS
* 应用场景：图形处理、连通性问题

dfs

```TypeScript
function numIslands (grid: string[][]): number {
  if (grid.length === 0) return 0

  const rows = grid.length
  const cols = grid[0].length
  let count = 0

  // DFS遍历整个岛屿并标记
  const dfs = (row: number, col: number) => {
    // 边界检查或已访问（水域）
    if (row < 0 || row >= rows || col < 0 || col >= cols || grid[row][col] === '0') {
      return
    }

    grid[row][col] = '0'

    // 四个方向DFS
    dfs(row - 1, col) // 上
    dfs(row + 1, col) // 下
    dfs(row, col - 1) // 左
    dfs(row, col + 1) // 右
  }

  // 遍历网格
  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < cols; col++) {
      if (grid[row][col] === '1') {
        count++
        dfs(row, col)
      }
    }
  }

  return count
}
```
