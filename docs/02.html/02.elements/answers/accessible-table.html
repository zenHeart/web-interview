可访问性要点：

  • caption: 为表格提供清晰的标题和描述
  • scope="col": 标识列表头
  • scope="row": 标识行表头
  • scope="colgroup": 标识列组表头
  • headers属性: 在复杂表格中建立单元格与表头的关联
  • id属性: 为表头提供唯一标识符，供headers属性引用

屏幕阅读器体验: 这些属性帮助屏幕阅读器用户理解表格结构，在浏览时能清楚知道当前单元格对应的行头和列头信息。
