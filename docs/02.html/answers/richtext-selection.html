Selection API 核心概念

Selection API 允许我们获取用户选中的文本范围，包括起始位置、结束位置、选中的内容等。Range API 则提供了更精细的文本范围操作能力。

请在此区域选择文本进行测试

这是一段演示文本，您可以用鼠标拖拽来选择其中的任意部分。Selection API 会实时捕获您的选择操作，并显示相关信息。

支持的功能包括：获取选中文本、获取选择范围、计算选择位置、检测选择方向等。尝试选择不同的文本段落，观察下方状态面板中的实时信息变化。

技术要点：通过监听 mouseup 和 selectionchange 事件来捕获用户的文本选择操作。

⚡ 高级划词操作

Range API 与文本操作

Range API 提供了对文本范围的精确控制，支持插入、删除、提取、克隆等操作。结合 Selection API 可以实现复杂的文本编辑功能。

可编辑的富文本区域

这是一个支持编辑的文本区域。您可以选择文本后使用上方的按钮来应用各种格式。

支持的操作包括：高亮显示、加粗文本、斜体文本、下划线文本等。

尝试选择一些文本，然后点击上方的格式按钮来应用样式。您也可以直接在此区域输入新的内容。

🖱️ 自定义右键菜单

contextmenu 事件与自定义菜单

通过监听 contextmenu 事件并结合 Selection API，可以在用户右键点击选中文本时显示自定义菜单，提供丰富的文本操作选项。

右键菜单演示区域

在此区域选择文本后点击右键，将显示自定义菜单而不是浏览器默认菜单。

菜单选项包括：复制、剪切、粘贴、格式化、搜索等功能。每个菜单项都会根据当前选择状态动态启用或禁用。

这种技术广泛应用于在线文档编辑器、代码编辑器、富文本编辑器等场景中。

🛠️ 浮动工具栏

动态定位与工具栏

根据选中文本的位置动态显示浮动工具栏，提供快速的文本操作入口。需要计算选择范围的位置并动态调整工具栏位置。

浮动工具栏演示

选择此区域中的文本时，会在选择位置附近显示浮动工具栏。

工具栏会自动计算最佳显示位置，避免超出视窗边界。点击工具栏按钮可以快速应用格式。

这种交互方式提供了更直观的用户体验，类似于 Google Docs、Notion 等现代编辑器的设计。
