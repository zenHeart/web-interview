2. 事件对象属性对比

PROPERTIES

target vs currentTarget

理解事件对象中两个重要属性的区别：

event.target
触发事件的元素
始终指向实际被点击的元素（不会变化）
event.currentTarget
当前处理事件的元素
指向当前绑定事件监听器的元素（会变化）
this
事件处理器中的this
等同于event.currentTarget（非箭头函数）
event.eventPhase
当前事件阶段
1=捕获 2=目标 3=冒泡
