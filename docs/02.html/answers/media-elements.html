HTML5 媒体元素完整指南

1. <video> 视频元素基础用法

VIDEO

基础视频播放器

基础属性说明：

  • controls - 显示播放控制界面
  • poster - 视频加载前显示的封面图
  • width/height - 设置视频尺寸
  • preload - 预加载策略（none/metadata/auto）
<video controls poster="cover.jpg" preload="metadata"> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> 您的浏览器不支持视频标签。 </video>
VIDEO

响应式视频容器

响应式设计要点：

  • 使用相对单位和百分比设置尺寸
  • 保持宽高比使用padding-bottom技巧
  • 考虑移动端的数据流量和性能

2. <audio> 音频元素

AUDIO

音频播放器

示例音频文件
HTML5 Audio Demo

音频特有属性：

  • 通常不需要poster属性
  • 可以设置为背景音乐（谨慎使用autoplay）
  • 支持多种音频格式：MP3、OGG、WAV等
  • 移动端可能需要用户交互才能播放

5. 浏览器支持检测

DETECT

格式支持检测

您的浏览器支持情况：

// 检测视频格式支持 const video = document.createElement('video'); const formats = { 'MP4': 'video/mp4', 'WebM': 'video/webm', 'OGG': 'video/ogg' }; Object.entries(formats).forEach(([name, type]) => { const support = video.canPlayType(type); console.log(`${name}: ${support}`); });
💡 媒体元素最佳实践：
  • 格式兼容性：提供多种格式确保跨浏览器支持
  • 预加载策略：根据内容重要性选择合适的preload值
  • 自动播放：遵循浏览器政策，静音视频更容易自动播放
  • 移动优化：考虑数据流量，提供画质选择
  • 无障碍访问：提供字幕track和音频描述
  • 性能监控：监听加载和错误事件
