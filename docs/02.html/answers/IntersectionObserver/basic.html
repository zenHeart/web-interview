属性详解：

  • root: 观察的根元素，null 表示视窗
  • rootMargin: 根元素的边距，类似 CSS margin
  • threshold: 触发回调的可见比例阈值
  • target: 被观察的目标元素
  • isIntersecting: 是否与根元素相交
  • intersectionRatio: 相交区域占目标元素的比例
  • boundingClientRect: 目标元素的边界信息
  • rootBounds: 根元素的边界信息
  • intersectionRect: 相交区域的边界信息
