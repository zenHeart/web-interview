7. 列表元素选择指南

列表类型 HTML标签 使用场景 语义特点 常见错误
无序列表 <ul><li> 项目顺序不重要 并列关系 强行排序使用
有序列表 <ol><li> 有明确顺序/步骤 有序关系 仅为样式使用
描述列表 <dl><dt><dd> 术语和定义 键值对关系 混用li元素
💡 列表可访问性要点：
  • 为复杂列表提供aria-label或aria-describedby
  • 避免仅为视觉效果而破坏列表语义
  • 确保列表项之间的逻辑关系清晰
  • 在描述列表中，一个dt可以对应多个dd
  • 使用CSS而非HTML来控制列表的视觉样式
