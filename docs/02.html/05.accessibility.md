## 按钮组件的可访问性该如何实现？ {#p0-a11y-button}

<Answer>

**核心要点**

- 使用 `button` 而非 `div`，天然可聚焦与键盘可触达
- 状态宣告：结合 `role="status"` 或 `aria-live` 提示结果

## 模态对话框如何保证键盘可达和焦点管理？ {#p1-a11y-modal}

<Answer>

**核心要点**

- 语义：`role="dialog"` + `aria-modal="true"` + `aria-labelledby/aria-describedby`
- 焦点：开启时将焦点移入，关闭时还原；Esc 关闭
