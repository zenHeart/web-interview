# 编码题

这里编码题的重点在于考察对 JavaScript 语言本身的特性理解和运用能力。分为如下子主题

1. [语法和 API](./01.syntax-api.md) 聚焦基础语法和内置 API，适合考察语言基本功。
2. [核心概念](./02.core-concept.md) 突出对 JS 运行机制、作用域、闭包、原型链等核心知识的理解和应用能力
3. [工具函数](./03.utils.md) 考察对常用工具函数的编写和使用能力, 例如 `lodash、dayjs` 等三方常用库的使用 API 及实现
4. [业务代码](./04.business.md) 关注实际项目场景下的代码优化与理解，体现工程能力。
5. [其他](./05.other.md) 补充开放性、规范性等无法归类但有价值的题目，保证分类完整性。通常是一些深挖类和综合题目。

:::tip

:::
