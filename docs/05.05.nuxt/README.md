# Nuxt 面试题

本目录包含 Nuxt 相关的面试题目，涵盖 Nuxt 框架的核心概念、开发实践和高级特性。

## 目录结构

- `00.concept.md` - Nuxt 核心概念
- `01.directory-structure.md` - 目录结构
- `02.rendering-modes.md` - 渲染模式
- `03.auto-imports.md` - 自动导入
- `04.modules.md` - 模块系统
- `coding.md` - 编程题

## 题目分类

### P0 必考知识点

- Nuxt 核心概念和优势
- 目录结构的作用和约定
- 渲染模式的区别和选择
- 自动导入机制

### P1 高频知识点

- 模块开发和集成
- 插件系统使用
- 中间件应用场景
- 服务端功能实现

### P2 常规知识点

- 内容管理 (Nuxt Content)
- 部署和优化策略
- 性能优化技巧
- 与 Vue 的区别

## 学习建议

1. **基础阶段**：重点掌握 Nuxt 核心概念和目录结构
2. **进阶阶段**：深入学习渲染模式和自动导入机制
3. **高级阶段**：掌握模块开发和性能优化技巧
