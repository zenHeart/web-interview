
1. `<keep-alive>` 可以使被包含的组件保留在内存中，而不是每次重新渲染的时候销毁并重建，从而提高了应用的性能。
2. `<keep-alive>` 的核心能力包括
   1. **缓存组件**：当一个组件被包裹在 `<keep-alive>` 中时，它会被缓存起来，而不是被销毁。可以通过 `include` 和 `exclude` 属性来控制哪些组件应该被缓存，哪些不应该被缓存。
   2. **缓存数量控制** `max` 属性来限制缓存的组件数量，超过这个数量时，最久未使用的组件会被销毁。内部采用 [LRU](https://en.wikipedia.org/wiki/Cache_replacement_policies#Least_recently_used_(LRU)) 算法来管理缓存的组件。
   3. **生命周期钩子**：当一个被缓存的组件被重新渲染时，它会被激活，而不是重新创建。相反，当它不再需要时，它会被停用，但仍然保留在内存中。`deactivated` 钩子会在组件被停用时调用，`activated` 钩子会在组件被激活时调用。
      1. unmounted 和 mounted 也会触发激活和停用的钩子。
      2. 对于 keep-alive 的内部子组件也会触发上述钩子
   4. **条件渲染**：可以通过 `include` 和 `exclude` 属性来控制哪些组件应该被缓存，哪些不应该被缓存。
