# 登录页体验反馈

> **Disclaimer**：
> 本文档仅作为个人体验观察记录，所列问题均为较小的甚至很难察觉的用户体验优化空间
> 部分问题也许是 feature 或者已有其他考量，此处仅抛出些许反馈

## 动画

### 半浮层

描述：FAQ 详情页面的半浮层动画在多次打开时失效
影响：轻微的用户体验问题

复现步骤：

1. 进入 Jerry App 首页（未登录状态）
2. 点击左上角 `Help` 进入 FAQ 列表
3. 首次点击任意 FAQ 问题时，半浮层会有从下至上的渐入动画
4. 关闭详情页，渐出动画未出现
5. 再次点击相同 FAQ 问题，渐入动画也不再出现

### 输入框

描述：首页电话号码输入框在获得焦点时出现分段动画
影响：轻微的用户体验问题

复现步骤：

1. 进入 Jerry App 首页（未登录状态）
2. 点击 "Enter cell phone number" 输入框
3. 页面上推动画分两段执行：
   - 第一段：上推距离 = 键盘高度 - x
   - 第二段：上推距离 = x
   （其中 x 约等于输入框顶部到页面底部的距离）

注：在某些情况下，第二段动画结束时，光标会刚好与键盘顶部对齐
（可以试着在键盘弹出的时候，稍微滚动下内容，关闭键盘再尝试打开，会比较容易复现该情况）

## 闪烁问题

### FAQ 标签组列表

描述：FAQ 分类页面中，在滚动切换标签时出现高亮样式溢出
影响：轻微的用户体验问题

复现步骤：

1. 进入 Jerry App 首页（未登录状态）
2. 点击左上角 `Help` 进入 FAQ 列表
3. 选择 `All questions` 中的 `Insurance` 分类
4. 向下滚动至底部，此时 `Billing` 标签高亮
5. 向上滚动时，`Billing` 标签周围区域出现高亮闪烁

### 启动屏幕

描述：App 冷启动时，SplashScreen 退出过程中出现白屏闪烁
影响：轻微的用户体验问题

复现步骤：

1. 完全退出 Jerry App（结束进程）
2. 重新启动 App，观察启动过程
3. 启动流程出现如下顺序：
   SplashScreen → 隐藏（包含状态栏）→ 白屏 → 状态栏出现 → 动画欢迎页
