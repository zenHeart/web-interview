# 如何实现一小时内的 Top10 播放榜？ {#P0-top10k}

<Answer>

**核心概念/解决方案:**

- 数据采集：事件流（video_id, ts, user_id），去重与采样
- 窗口统计：滑动/滚动窗口，延迟到达与纠错；近实时与最终一致性
- 排序与查询：Redis ZSET/TopK 结构，按窗口时间分桶

## 基本需求分析

- 统计最近1小时内视频的播放量
- 实时返回 Top 10 播放量最高的视频
- 系统需要高可用、低延迟

## 系统设计方案

1. **数据收集层**
   - 使用消息队列(Kafka)接收视频播放事件
   - 每个播放事件包含：video_id, timestamp, user_id 等信息

2. **统计层**
   - 使用滑动窗口计数
   - Redis 存储格式：`ZADD video_counts video_id count`
   - 定期清理超过1小时的数据

3. **查询层**
   - Redis ZREVRANGE 命令获取 Top 10
   - 结果缓存，降低压力

## 可能的追问

1. 如何处理播放量暴增的情况？
2. 如何确保数据准确性？
3. 系统扩展性如何保证？
4. 如何处理时区问题？

**面试官视角:**

- 关注迟到/乱序事件处理、去重策略与内存成本；一致性与延迟权衡

**延伸阅读:**

- Count-Min Sketch/TopK、Flink Window 机制、Redis Sorted Set
