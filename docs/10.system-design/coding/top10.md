# 为 Youtube 用户设计出一个小时内 top 10 播放量的视频 {#p0-top10k}

### 基本需求分析

- 统计最近1小时内视频的播放量
- 实时返回 Top 10 播放量最高的视频
- 系统需要高可用、低延迟

### 系统设计方案

1. **数据收集层**
   - 使用消息队列(Kafka)接收视频播放事件
   - 每个播放事件包含：video_id, timestamp, user_id 等信息

2. **统计层**
   - 使用滑动窗口计数
   - Redis 存储格式：`ZADD video_counts video_id count`
   - 定期清理超过1小时的数据

3. **查询层**
   - Redis ZREVRANGE 命令获取 Top 10
   - 结果缓存，降低压力
