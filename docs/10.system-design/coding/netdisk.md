
# 如何设计云盘系统？ {#P1-cloud-disk}

<Answer>

**核心概念/解决方案:**

- 上传：分片/断点续传/秒传（MD5）/并发与重试退避；服务端合并
- 存储：对象存储 + 元数据数据库；多副本/跨区域、版本与回收站
- 下载：范围请求/断点续传、加速与鉴权；分享/权限模型
- 治理：配额/生命周期/归档、病毒扫描与敏感内容识别

**示例说明:**

- 结合签名直传（STS）与回调校验；客户端并发/限流示例

**面试官视角:**

- 关注一致性/幂等（重复上传、重试）、大文件可靠性、权限与审计

**延伸阅读:**

- S3 多分段上传、Range/ETag、对象存储一致性

</Answer>
