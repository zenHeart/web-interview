
# 如何设计图床系统？ {#P1-image-hosting}

<Answer>

**核心概念/解决方案:**

- 上传：分片上传/断点续传/MD5 秒传；鉴权与风控
- 存储：对象存储 + CDN + 处理服务（裁剪/格式转换/WebP/AVIF）
- 缓存：多级缓存与预热、Vary/Key 设计、签名 URL
- 运营：配额/清理/版本与回收；审计与鉴黄/病毒扫描

## 核心功能

1. **上传功能**
   - 分片上传
   - 断点续传
   - MD5校验

2. **存储系统**
   - 分布式存储
   - CDN加速
   - 图片处理服务

3. **缓存策略**
   - 多级缓存
   - 预热机制
   - 过期策略

## 可能的追问

1. 如何处理上传失败？
2. 如何优化上传速度？
3. 如何处理大文件？
4. 如何确保数据安全？

**面试官视角:**

- 关注热点/大图/原图保留策略、鉴权与防盗链、成本与性能

**延伸阅读:**

- CDN 缓存策略、图片处理网关、S3/OSS 安全与签名
