# 编码

本目录的题目采用“文件名编号”进行排序，配合自动生成的侧边栏，保证阅读与练习的渐进路径一致。

## 排序规则

1. 按照优先级从高到低排序：P0 → P1 → P2 → P3 → P4。
2. 同一优先级内，按学习路径与依赖关系排列（由基础到工程与系统）：
   - 组件能力 → 系统/业务设计 → 安全与鉴权 → 平台与工程化 → 隔离与运行时 → 数据计算与指标。
3. 排序以两位数字编号为准，文件命名决定在侧边栏中的顺序。

优先级的定义与判定依据请参考 `contributors/template/01.question.md` 中的优先级说明（P0–P4）。

## 命名规范

- 文件名采用：`<两位序号>.<主题英文别名>.md`
- 例如：`01.components.md`、`02.feed.md`、`03.login.md`
- 新增题目时：
  - 依据题目的优先级（P0–P4）与学习路径确定插入位置；
  - 选择合适的两位序号，必要时对后续文件整体顺延；
  - 标题中的锚点仍保留原有 `#P{level}-<id>`，用于检索与交叉引用。
