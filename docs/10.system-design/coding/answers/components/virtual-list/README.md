# 虚拟列表

## 知识点

1. 核心组成部件
   1. 列表容器，自动撑满父容器，`overflow: scroll` 允许溢出滚动
   2. 滚动容器实现滚动占位，高度为 `itemHeight * items.length`，不可见
   3. 列表项，渲染每个独立的列表项，注意每个列表的位置取决于滚动位置 `scrollTop`
   4. 滚动窗口，用来显示滚动到 `scrollTop` 位置的时候因该渲染的列表项条目
      1. 滚动窗口的高度必须大于列表容器
      2. 滚动窗口的刷新必须保证下边不溢出
   5. 动态列表
      1. 需要预估高度
      2. 需要使用 ResizeObserver 监听容器大小变化, 动态改变高度
