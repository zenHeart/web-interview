CSS 动画与过渡演示

过渡 vs 动画对比

Transition（过渡）

悬停触发，平滑状态变化

Animation（动画）

自动播放，关键帧控制

特性 Transition Animation
触发方式 需要状态变化触发 可以自动播放
控制精度 只能定义开始和结束状态 可以定义多个关键帧
循环播放 不支持 支持无限循环
应用场景 交互反馈、悬停效果 复杂动画、装饰效果

关键帧动画演示

滑动动画

使用 @keyframes 定义复杂动画序列

@keyframes slide { 0% { transform: translateX(-50px); opacity: 0; } 25% { transform: translateX(0); opacity: 1; } 75% { transform: translateX(0); opacity: 1; } 100% { transform: translateX(50px); opacity: 0; } } .keyframe-demo { animation: slide 3s ease-in-out infinite; }

性能优化演示

优化版本（推荐）

使用 transform，GPU 加速

未优化版本

使用 left 属性，触发重排

/* 优化版本 */ .optimized { will-change: transform; transition: transform 0.3s ease; } .optimized:hover { transform: translateX(20px); } /* 未优化版本 */ .unoptimized { transition: left 0.3s ease; position: relative; left: 0; } .unoptimized:hover { left: 20px; }

动画控制演示

// JavaScript 控制动画 function playAnimation() { element.style.animationPlayState = 'running'; } function pauseAnimation() { element.style.animationPlayState = 'paused'; } // 监听动画事件 element.addEventListener('animationend', () => { console.log('动画结束'); });

动画最佳实践

  • 使用 GPU 加速属性：transform、opacity、filter
  • 避免触发重排：width、height、margin、padding
  • 合理使用 will-change：提前告知浏览器优化
  • 控制动画时长：保持 60fps 的流畅度
  • 考虑用户体验：提供暂停和减少动画的选项
