实现代码

HTML 结构：

<div class="card-container">
  <div class="card">
    <div class="card-front">正面内容</div>
    <div class="card-back">背面内容</div>
  </div>
</div>

CSS 样式：

.card-container {
  perspective: 1000px;
  width: 200px;
  height: 300px;
}

.card {
  position: relative;
  width: 100%;
  height: 100%;
  transform-style: preserve-3d;
  transition: transform 0.6s;
  cursor: pointer;
}

.card.flipped {
  transform: rotateY(180deg);
}

.card-front,
.card-back {
  position: absolute;
  width: 100%;
  height: 100%;
  backface-visibility: hidden;
  border-radius: 10px;
  display: flex;
  align-items: center;
  justify-content: center;
}

.card-back {
  transform: rotateY(180deg);
}

JavaScript 控制：

function toggleFlip(card) {
  card.classList.toggle('flipped');
}

关键属性说明

  • perspective：设置 3D 视角距离，值越小效果越明显
  • transform-style: preserve-3d：保持 3D 变换效果
  • backface-visibility: hidden：隐藏元素背面
  • transition：添加过渡动画效果
  • transform: rotateY(180deg)：Y轴旋转180度
