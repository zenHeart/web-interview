相对定位(relative)

参考元素（静态定位）

后续元素不受影响

绝对定位(absolute)

容器内的普通元素

其他元素会忽略绝对定位元素

固定定位(fixed)

固定在右上角的元素

固定定位元素相对于浏览器窗口定位，不会随页面滚动。

定位特点：

  • static：默认定位，按文档流排列
  • relative：相对于自身原位置偏移
  • absolute：相对于最近的定位祖先元素
  • fixed：相对于浏览器窗口，不随滚动移动
  • sticky：滚动到指定位置时变为固定定位
