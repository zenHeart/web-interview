CSS 居中布局演示

水平垂直居中方法

1. Flexbox 居中（推荐）
使用 display: flex 配合 align-items 和 justify-content 实现居中
Flexbox
居中
.container { display: flex; align-items: center; justify-content: center; }
2. Grid 居中
使用 display: grid 配合 place-items 实现居中
Grid
居中
.container { display: grid; place-items: center; }
3. 绝对定位 + Transform
使用绝对定位配合 transform: translate(-50%, -50%) 实现居中
绝对定位
+ Transform
.container { position: relative; } .centered { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }
4. 绝对定位 + Margin Auto
使用绝对定位配合 margin: auto 实现居中（需要固定尺寸）
绝对定位
+ Margin Auto
.centered { position: absolute; top: 0; left: 0; right: 0; bottom: 0; margin: auto; width: 100px; height: 60px; }

水平居中方法

5. 行内元素居中
使用 text-align: center 实现行内元素的水平居中
行内元素
居中
.container { text-align: center; } .centered { display: inline-block; }
6. 表格居中
使用 display: table 配合 vertical-align 实现居中
表格
居中
.container { display: table; } .centered { display: table-cell; vertical-align: middle; text-align: center; }
7. Line-height 居中
使用 line-height 实现单行文本的垂直居中
Line-height
居中
.container { line-height: 200px; text-align: center; } .centered { display: inline-block; vertical-align: middle; line-height: normal; }

未知尺寸元素居中

8. 未知尺寸元素居中
使用绝对定位 + transform 实现未知尺寸元素的居中
未知尺寸
元素居中
自适应内容
.centered { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); width: auto; height: auto; min-width: 100px; min-height: 60px; }

方法对比

方法 优点 缺点 适用场景
Flexbox 语法简洁、浏览器支持好、响应式友好 需要容器支持 现代布局首选方案
Grid 语法最简洁、功能强大 浏览器支持相对较新 复杂布局、现代项目
绝对定位 + Transform 兼容性好、支持未知尺寸 脱离文档流、代码相对复杂 弹窗、工具提示
绝对定位 + Margin 兼容性最好 需要固定尺寸、代码复杂 固定尺寸元素
行内元素居中 简单易用 只支持水平居中 文本、按钮等行内元素

最佳实践建议

  • 现代项目：优先使用 Flexbox 或 Grid
  • 兼容性要求高：使用绝对定位 + transform
  • 未知尺寸元素：使用绝对定位 + transform
  • 行内元素：使用 text-align: center
  • 单行文本：使用 line-height
