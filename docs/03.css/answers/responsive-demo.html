响应式图片

图片会根据容器宽度自动缩放，保持宽高比：

.responsive-image { width: 100%; height: auto; max-width: 100%; }

响应式表格

表格在小屏幕上可以水平滚动：

设备类型 屏幕宽度 布局方式 特点
手机 < 768px 单列布局 垂直堆叠，触摸友好
平板 768px - 1024px 双列布局 中等屏幕优化
桌面 > 1024px 多列布局 充分利用屏幕空间
.table-demo { overflow-x: auto; } .responsive-table { width: 100%; min-width: 600px; }

响应式文本

使用 clamp() 函数实现响应式字体大小：

这是一段响应式文本，字体大小会根据视口宽度自动调整。 在桌面端显示较大字体，在移动端显示较小字体，确保良好的可读性。

.responsive-text { font-size: clamp(1rem, 2.5vw, 1.5rem); line-height: 1.6; }

响应式按钮

按钮的内边距会根据屏幕大小自动调整：

响应式按钮 另一个按钮
.responsive-button { padding: clamp(0.5rem, 2vw, 1rem) clamp(1rem, 4vw, 2rem); font-size: clamp(0.875rem, 2vw, 1rem); }

媒体查询断点

常用的响应式断点设置：

/* 手机端 */ @media (max-width: 768px) { .nav-menu { display: none; } .grid-container { grid-template-columns: 1fr; } } /* 小屏手机 */ @media (max-width: 480px) { .container { padding: 0 10px; } } /* 平板端 */ @media (min-width: 769px) and (max-width: 1024px) { .grid-container { grid-template-columns: repeat(2, 1fr); } } /* 桌面端 */ @media (min-width: 1025px) { .grid-container { grid-template-columns: repeat(3, 1fr); } }
