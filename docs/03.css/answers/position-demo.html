CSS Position 属性演示

Position 属性说明：

  • static（默认）：元素按照正常文档流定位
  • relative：相对于元素原本位置进行偏移，不脱离文档流
  • absolute：相对于最近的定位祖先元素定位，脱离文档流
  • fixed：相对于视口定位，脱离文档流
  • sticky：在正常流和固定定位之间切换

关键要点：

  • 文档流：static 和 relative 保持在文档流中，absolute 和 fixed 脱离文档流
  • 定位参考：relative 相对于自身，absolute 相对于最近的定位祖先，fixed 相对于视口
  • 层级控制：使用 z-index 控制元素的堆叠顺序
  • 实际应用：absolute 常用于下拉菜单、tooltip，fixed 用于固定导航栏，sticky 用于吸顶效果
