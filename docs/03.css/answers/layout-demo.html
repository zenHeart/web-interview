CSS 常见布局演示

三栏布局 - Flexbox 方法

Flexbox 三栏布局
左侧栏
固定宽度 200px
中间栏
自适应宽度
右侧栏
固定宽度 200px

Flexbox 三栏布局代码：

.container {
  display: flex;
  min-height: 200px;
}

.left, .right {
  width: 200px;
  flex-shrink: 0;
}

.center {
  flex: 1;
}

三栏布局 - Grid 方法

Grid 三栏布局
左侧栏
固定宽度 200px
中间栏
自适应宽度
右侧栏
固定宽度 200px

Grid 三栏布局代码：

.container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  min-height: 200px;
}

圣杯布局

圣杯布局（中间栏优先渲染）
中间栏
优先渲染，自适应宽度
左侧栏
固定宽度 200px
右侧栏
固定宽度 200px

圣杯布局代码：

.container {
  padding: 0 200px;
}

.center {
  float: left;
  width: 100%;
}

.left, .right {
  float: left;
  width: 200px;
  margin-left: -100%;
  position: relative;
  left: -200px;
}

.right {
  left: 200px;
  margin-left: -200px;
}

布局特点对比

布局方法 优点 缺点 兼容性
Flexbox 简单易用，响应式好 IE9 以下不支持 现代浏览器
Grid 功能强大，二维布局 IE 不支持 现代浏览器
圣杯布局 兼容性好，中间优先 代码复杂，维护困难 所有浏览器
