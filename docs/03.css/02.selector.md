# 基础概念✅

本主题涵盖CSS的核心概念和基础理论，包括选择器、层叠、继承等基础概念。

## 什么是CSS选择器？{#p0-selector}

<Answer>

**核心概念**

CSS选择器是用于选择HTML元素并应用样式的模式。选择器决定了哪些元素会受到CSS规则的影响。

**选择器类型**

1. **简单选择器**
   - 元素选择器：`div`、`p`、`span`
   - 类选择器：`.class-name`
   - ID选择器：`#id-name`
   - 属性选择器：`[type="text"]`
   - 通配符选择器：`*`

2. **组合选择器**
   - 后代选择器：`div p`
   - 子选择器：`div > p`
   - 相邻兄弟选择器：`h1 + p`
   - 通用兄弟选择器：`h1 ~ p`

3. **伪类选择器**
   - 状态伪类：`:hover`、`:focus`、`:active`
   - 结构伪类：`:first-child`、`:nth-child(n)`
   - 否定伪类：`:not(.class)`

4. **伪元素选择器**
   - `::before`、`::after`
   - `::first-line`、`::first-letter`

**选择器优先级**

选择器优先级按以下规则计算：

1. **内联样式**：1000分
2. **ID选择器**：100分
3. **类选择器、属性选择器、伪类**：10分
4. **元素选择器、伪元素**：1分
5. **通配符、继承**：0分

**代码示例**

```css
/* 简单选择器 */
.title { color: red; }
#header { background: blue; }
[type="text"] { border: 1px solid; }

/* 组合选择器 */
.container .item { margin: 10px; }
nav > ul { list-style: none; }
h1 + p { font-size: 18px; }

/* 伪类选择器 */
.button:hover { background: yellow; }
li:first-child { font-weight: bold; }
p:not(.highlight) { opacity: 0.7; }

/* 伪元素选择器 */
p::before { content: "→ "; }
p::first-line { font-variant: small-caps; }
```

**面试官视角**

- **差**：不了解选择器类型，无法区分优先级
- **良**：理解基本选择器，知道优先级计算规则
- **优**：深入理解选择器机制，能优化选择器性能

**延伸阅读**

## 什么是CSS层叠和继承？{#p0-cascade-inheritance}

<Answer>

**核心概念**

CSS层叠（Cascade）和继承（Inheritance）是CSS的两个核心机制，决定了样式如何应用到元素上。

**层叠机制**

层叠决定了当多个CSS规则应用到同一个元素时，哪个规则会生效。

**优先级顺序（从高到低）**

1. **!important声明**
2. **内联样式**
3. **ID选择器**
4. **类选择器、属性选择器、伪类**
5. **元素选择器、伪元素**
6. **通配符选择器**

**代码示例**

```css
/* 优先级示例 */
#header { color: red; }        /* 100分 */
.title { color: blue; }        /* 10分 */
h1 { color: green; }           /* 1分 */

/* 相同优先级，后面的覆盖前面的 */
p { color: red; }
p { color: blue; }  /* 生效 */

/* !important 最高优先级 */
p { color: red !important; }
#header p { color: blue; }  /* 仍然红色 */
```

**继承机制**

某些CSS属性会从父元素继承到子元素。

**可继承的属性**

- 文本相关：`color`、`font-family`、`font-size`
- 列表相关：`list-style`
- 表格相关：`border-collapse`

**不可继承的属性**

- 盒模型：`width`、`height`、`margin`、`padding`
- 定位：`position`、`top`、`left`
- 背景：`background`、`border`

**代码示例**

```css
/* 继承示例 */
.parent {
  color: red;
  font-size: 16px;
  background: yellow;  /* 不继承 */
}

.child {
  /* 继承 color 和 font-size */
  /* 不继承 background */
}
```

**实际应用**

```css
/* 全局样式继承 */
body {
  font-family: Arial, sans-serif;
  color: #333;
  line-height: 1.6;
}

/* 特定元素覆盖继承 */
.special {
  color: blue;  /* 覆盖继承的color */
}
```

**面试官视角**

- **差**：不了解层叠和继承概念
- **良**：理解基本机制，知道常见可继承属性
- **优**：深入理解机制，能优化样式结构

**延伸阅读**

- [MDN: CSS层叠和继承](https://developer.mozilla.org/zh-CN/docs/Learn/CSS/Building_blocks/Cascade_and_inheritance) - 学习指南
- [CSS层叠详解](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Cascade) - 官方文档

## 什么是CSS盒模型？{#p0-box-model}

<Answer>

**核心概念**

CSS盒模型描述了元素在页面中占据空间的方式，每个元素都被视为一个矩形盒子，包含内容、内边距、边框和外边距。

**盒模型组成**

```
┌─────────────────────────────────────┐
│              margin                 │
│  ┌─────────────────────────────┐    │
│  │          border             │    │
│  │  ┌─────────────────────┐    │    │
│  │  │      padding        │    │    │
│  │  │  ┌─────────────┐    │    │    │
│  │  │  │   content   │    │    │    │
│  │  │  └─────────────┘    │    │    │
│  │  └─────────────────────┘    │    │
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘
```

**两种盒模型**

1. **标准盒模型（content-box）**
   - `width/height` 只包含内容区域
   - 实际占用空间 = width/height + padding + border + margin
   - 默认盒模型

2. **IE盒模型（border-box）**
   - `width/height` 包含内容、内边距和边框
   - 实际占用空间 = width/height + margin
   - 通过 `box-sizing: border-box` 设置

**代码示例**

```css
/* 标准盒模型 */
.box-standard {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  margin: 10px;
  /* 实际宽度：200 + 20*2 + 5*2 = 250px */
}

/* IE盒模型 */
.box-border-box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  margin: 10px;
  /* 实际宽度：200px（包含padding和border） */
}
```

**实际应用**

```css
/* 全局设置border-box，便于布局计算 */
* {
  box-sizing: border-box;
}

/* 响应式布局中使用border-box */
.container {
  width: 100%;
  padding: 0 20px;
  /* 宽度计算更直观 */
}
```

**面试官视角**

- **差**：不了解盒模型概念，无法区分两种盒模型
- **良**：理解盒模型组成，知道如何设置box-sizing
- **优**：深入理解盒模型对布局的影响，能合理选择盒模型类型

**延伸阅读**

- [MDN: 盒模型](https://developer.mozilla.org/zh-CN/docs/Web/CSS/CSS_Box_Model) - 官方文档
- [CSS盒模型详解](https://developer.mozilla.org/zh-CN/docs/Learn/CSS/Building_blocks/The_box_model) - 学习指南

## 什么是BFC？{#p0-bfc}

<Answer>

**核心概念**

BFC（Block Formatting Context，块级格式化上下文）是CSS布局中的一个重要概念，它是一个独立的渲染区域，具有特定的布局规则。

**BFC特性**

1. **包含浮动元素**：BFC会包含其内部的所有浮动元素
2. **阻止外边距合并**：BFC内的外边距不会与外部元素的外边距合并
3. **阻止文字环绕**：BFC会阻止浮动元素与BFC内的文字重叠
4. **独立布局**：BFC内的元素布局不受外部影响

**创建BFC的方法**

1. 根元素（`<html>`）
2. `display: flow-root`（推荐）
3. 浮动元素（`float` 不为 `none`）
4. 绝对定位元素（`position: absolute/fixed`）
5. 行内块元素（`display: inline-block`）
6. 表格单元格（`display: table-cell`）
7. `overflow` 不为 `visible` 的块级元素

**代码示例**

```css
/* 创建BFC的方法 */
.bfc-container {
  /* 方法1：使用flow-root（推荐） */
  display: flow-root;
  
  /* 方法2：使用overflow */
  overflow: hidden;
  
  /* 方法3：使用float */
  float: left;
  
  /* 方法4：使用position */
  position: absolute;
}
```

**实际应用**

```css
/* 清除浮动 */
.clearfix::after {
  content: '';
  display: table;
  clear: both;
}

/* 使用BFC清除浮动 */
.clearfix {
  display: flow-root;
}

/* 阻止外边距合并 */
.margin-container {
  display: flow-root;
}

.margin-item {
  margin: 20px;
  /* 在BFC内，外边距不会合并 */
}
```

**面试官视角**

- **差**：不了解BFC概念，无法解决相关布局问题
- **良**：理解BFC基本概念，知道如何创建BFC
- **优**：深入理解BFC机制，能灵活运用解决复杂布局问题

**延伸阅读**

- [MDN: 块级格式化上下文](https://developer.mozilla.org/zh-CN/docs/Web/Guide/CSS/Block_formatting_context) - 官方文档
- [CSS BFC详解](https://developer.mozilla.org/zh-CN/docs/Web/CSS/CSS_display/Block_formatting_context) - 详细说明

## 什么是CSS视觉格式化模型？{#p0-visual-formatting-model}

<Answer>

**核心概念**

CSS视觉格式化模型定义了浏览器如何在可视化设备上渲染文档树，它决定了元素如何生成盒模型以及这些盒模型如何排列。

**格式化上下文类型**

1. **块级格式化上下文（BFC）**
   - 垂直排列元素
   - 包含浮动元素
   - 阻止外边距合并

2. **内联格式化上下文（IFC）**
   - 水平排列元素
   - 处理文本和行内元素
   - 创建行框（Line Box）

3. **Flex格式化上下文**
   - 弹性布局
   - 主轴和交叉轴排列

4. **Grid格式化上下文**
   - 网格布局
   - 二维布局系统

**定位策略**

1. **正常流（Normal Flow）**
   - 元素按照文档顺序排列
   - 块级元素垂直排列
   - 内联元素水平排列

2. **浮动（Float）**
   - 元素脱离正常流
   - 向左或向右浮动
   - 其他元素环绕

3. **绝对定位（Absolute Positioning）**
   - 元素脱离正常流
   - 相对于最近的定位祖先定位
   - 不影响其他元素布局

**代码示例**

```css
/* 正常流 */
.normal-flow {
  /* 默认定位，在正常流中 */
}

/* 浮动 */
.float-left {
  float: left;
  width: 200px;
}

/* 绝对定位 */
.absolute {
  position: absolute;
  top: 0;
  left: 0;
}

/* Flex布局 */
.flex-container {
  display: flex;
  justify-content: space-between;
}

/* Grid布局 */
.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}
```

- **差**：不了解格式化模型概念
- **良**：理解基本格式化上下文类型
- **优**：深入理解格式化模型机制，能分析复杂布局

**延伸阅读**
