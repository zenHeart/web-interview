# 基础概念✅

## 什么是选择器，css 有哪些选择器？{#p0-css-selector}

<Answer>

选择器是匹配特定文档树元素的语法，选择器和属性声明组成一个规则集来控制匹配元素的样式。
常见的选择器有如下几种。

|**类型**|**选择器**|**示例**
|:---|:---|:---
|简单选择器|ID选择器|`#main { background: #fff; }`
||类选择器|`.box { padding: 10px; }`
||元素选择器|`div { color: red; }`
||属性选择器|`input[type="text"] { border: 1px solid; }`
||通配符选择器|`* { box-sizing: border-box; }`
||分组选择器|`h1, h2, h3 { margin: 0; }`
伪类/伪元素|状态伪类|`:checked、:disabled、:focus、:active`
||结构伪类|`li:first-child { font-weight: bold; }、li:last-child { font-style: italic; }、li:nth-child(2n) { background: #f0f0f0; }`
||交集伪类|`:is(.active, .selected) { color: green; }`
||否定伪类|`:not(.active) { opacity: 0.5; }`
||伪元素|`p::after { content: "*"; }、p::before { content: "Note: "; }`
复杂选择器|后代选择器|`ul li { list-style: none; }`
||子选择器|`div > p { margin: 0; }`
||相邻兄弟选择器|`h2 + p { color: green; }`
||通用兄弟选择器|`h2 ~ p { font-size: 14px; }`
||组合选择器|`div.box.active { border: 1px solid; }`

</Answer>
