# 选择器和优先级✅

本主题涵盖CSS选择器系统和优先级计算，包括各种选择器的使用方法和优先级规则。


## CSS选择器有哪些类型？ {#p0-selector-types}

<Answer>

**选择器分类**

CSS选择器按功能可分为以下几类：

### 1. 基础选择器

- **元素选择器**：`p {}` - 选择所有p元素
- **类选择器**：`.my-class {}` - 选择class为my-class的元素
- **ID选择器**：`#my-id {}` - 选择id为my-id的元素
- **通配符选择器**：`* {}` - 选择所有元素

### 2. 组合选择器

- **后代选择器**：`.parent .child {}` - 选择parent下的所有child元素
- **子元素选择器**：`.parent > .child {}` - 选择parent的直接子元素
- **相邻兄弟选择器**：`.sibling + p {}` - 选择紧邻sibling的p元素
- **通用兄弟选择器**：`.sibling ~ p {}` - 选择sibling后的所有p元素

### 3. 属性选择器

- **存在选择器**：`[attr]` - 选择有attr属性的元素
- **值选择器**：`[attr=value]` - 选择attr属性等于value的元素
- **前缀选择器**：`[attr^=value]` - 选择attr属性以value开头的元素
- **后缀选择器**：`[attr$=value]` - 选择attr属性以value结尾的元素
- **包含选择器**：`[attr*=value]` - 选择attr属性包含value的元素

### 4. 伪类选择器

- **状态伪类**：`:hover`、`:focus`、`:active`
- **结构伪类**：`:first-child`、`:last-child`、`:nth-child()`
- **表单伪类**：`:checked`、`:disabled`、`:required`

### 5. 伪元素选择器

- **内容伪元素**：`::before`、`::after`
- **文本伪元素**：`::first-line`、`::first-letter`

**实际应用示例**

```css
/* 基础选择器 */
.button { color: blue; }
#header { background: red; }

/* 组合选择器 */
nav > ul > li { margin: 10px; }
.container .item { padding: 5px; }

/* 属性选择器 */
input[type="text"] { border: 1px solid #ccc; }
a[href^="https"] { color: green; }

/* 伪类选择器 */
.button:hover { background: yellow; }
li:nth-child(odd) { background: #f0f0f0; }
```

**面试官视角**

- **差**：只知道基础选择器，无法使用复杂选择器
- **良**：掌握常用选择器，能写出基本的选择器组合
- **优**：熟练使用各种选择器，理解选择器性能，能优化选择器

**延伸阅读**

</Answer>

## CSS选择器优先级如何计算？ {#p0-selector-priority}

<Answer>

**优先级计算规则**

CSS选择器优先级通过特异性（Specificity）计算，规则如下：

### 1. 优先级权重

- **!important**：最高优先级，覆盖所有其他规则
- **内联样式**：1000分
- **ID选择器**：100分
- **类选择器、属性选择器、伪类**：10分
- **元素选择器、伪元素**：1分
- **通配符、组合符**：0分

### 2. 计算示例

```css
/* 优先级：100 + 10 + 1 = 111 */
#header .nav li { color: red; }

/* 优先级：10 + 1 = 11 */
.nav li { color: blue; }

/* 优先级：1 */
li { color: green; }
```

### 3. 特殊情况

- **相同优先级**：后定义的样式覆盖先定义的
- **继承样式**：优先级最低，比任何选择器都低
- **!important**：强制覆盖，但应谨慎使用

**实际应用**

```css
/* 避免过度使用!important */
.button {
  color: blue !important; /* 不推荐 */
}

/* 通过提高选择器特异性 */
.container .button {
  color: blue; /* 推荐 */
}

/* 使用更具体的选择器 */
#main .container .button {
  color: blue; /* 更推荐 */
}
```

**面试官视角**

- **差**：不了解优先级计算，经常使用!important
- **良**：理解基本优先级规则，能解决常见冲突
- **优**：深入理解优先级机制，能优化选择器，避免过度使用!important

**延伸阅读**

- [MDN: 优先级](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Specificity) - 官方文档
- [CSS层叠规则](https://www.w3.org/TR/CSS22/cascade.html#cascade) - W3C规范

</Answer>

## 什么是CSS层叠和继承？ {#p1-cascade-inheritance}

<Answer>

**CSS层叠概念**

CSS层叠（Cascade）是CSS的核心机制，决定了当多个样式规则应用于同一个元素时，哪个规则会生效。

### 1. 层叠规则

CSS层叠按照以下顺序确定样式优先级：

1. **用户代理样式**（浏览器默认样式）
2. **用户样式**（用户自定义样式）
3. **作者样式**（开发者编写的样式）
4. **!important声明**（强制优先级）

### 2. 继承机制

某些CSS属性会从父元素继承到子元素：

#### 可继承属性

- **文本相关**：`color`、`font-family`、`font-size`、`line-height`
- **列表相关**：`list-style`、`list-style-type`
- **表格相关**：`border-collapse`、`border-spacing`

#### 不可继承属性

- **盒模型相关**：`width`、`height`、`margin`、`padding`、`border`
- **定位相关**：`position`、`top`、`left`、`z-index`
- **显示相关**：`display`、`visibility`

**代码示例**

```css
/* 继承示例 */
body {
  color: blue; /* 会被所有子元素继承 */
  font-family: Arial, sans-serif;
}

/* 不可继承的属性需要显式设置 */
.container {
  margin: 20px; /* 子元素不会继承margin */
}

.child {
  margin: 10px; /* 需要显式设置 */
}
```

### 3. 继承控制

```css
/* 强制继承 */
.child {
  color: inherit; /* 强制继承父元素的color */
}

/* 阻止继承 */
.child {
  color: initial; /* 使用初始值 */
  font-size: unset; /* 使用unset值 */
}
```

**实际应用**

```css
/* 全局样式继承 */
:root {
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
  color: #333;
  line-height: 1.6;
}

/* 组件样式 */
.card {
  background: white;
  border: 1px solid #ddd;
  /* 文本样式会继承自:root */
}
```

**面试官视角**

- **差**：不了解层叠和继承机制
- **良**：理解基本层叠规则，知道常见可继承属性
- **优**：深入理解层叠机制，能合理利用继承减少代码重复

**延伸阅读**

- [MDN: CSS层叠](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Cascade) - 官方文档
- [CSS继承详解](https://developer.mozilla.org/zh-CN/docs/Web/CSS/inheritance) - 继承机制

</Answer>

## 如何优化CSS选择器性能？ {#p2-selector-performance}

<Answer>

**选择器性能优化**

CSS选择器性能直接影响页面渲染速度，需要从多个角度进行优化。

### 1. 选择器性能排序

从快到慢的选择器性能排序：

1. **ID选择器**：`#id` - 最快
2. **类选择器**：`.class` - 很快
3. **元素选择器**：`tag` - 快
4. **属性选择器**：`[attr]` - 中等
5. **伪类选择器**：`:hover` - 中等
6. **后代选择器**：`.parent .child` - 较慢
7. **通配符选择器**：`*` - 最慢

### 2. 优化策略

#### 避免过度嵌套

```css
/* 不推荐 - 过度嵌套 */
.container .wrapper .content .item .link { color: blue; }

/* 推荐 - 使用类名 */
.link { color: blue; }
```

#### 使用类选择器替代后代选择器

```css
/* 不推荐 */
.container .button { background: blue; }

/* 推荐 */
.button { background: blue; }
```

#### 避免使用通配符

```css
/* 不推荐 */
* { margin: 0; padding: 0; }

/* 推荐 */
body, h1, h2, h3, p, ul, li { margin: 0; padding: 0; }
```

### 3. 现代CSS优化

#### 使用CSS变量减少重复

```css
:root {
  --primary-color: #007bff;
  --secondary-color: #6c757d;
}

.button {
  background: var(--primary-color);
}

.link {
  color: var(--secondary-color);
}
```

#### 使用CSS Grid和Flexbox减少嵌套

```css
/* 使用Grid减少嵌套 */
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 20px;
}
```

### 4. 工具优化

#### 使用CSS预处理器

```scss
// Sass嵌套优化
.button {
  background: blue;
  
  &:hover {
    background: darkblue;
  }
  
  &--large {
    padding: 20px;
  }
}
```

#### 使用PostCSS优化

```css
/* 自动添加浏览器前缀 */
.button {
  display: flex;
  /* PostCSS会自动添加-webkit-等前缀 */
}
```

- **差**：不了解选择器性能，经常使用低效选择器
- **良**：知道基本性能规则，能避免明显低效的选择器
- **优**：深入理解性能机制，能系统性地优化CSS选择器

</Answer>
