# CSS 样式表

本学科关注网页样式和布局技术，涵盖从基础概念到现代布局技术的完整知识体系。

## 学科概述

CSS（Cascading Style Sheets）是用于描述网页视觉呈现的样式表语言。本学科按照从基础概念到实际应用的逻辑组织，确保学习者能够循序渐进地掌握CSS技术。

## 面试重点

### 必考知识点（P0）

- CSS盒模型和box-sizing
- CSS选择器和优先级
- CSS定位和布局
- Flexbox和Grid布局
- CSS层叠和继承

### 高频知识点（P1）

- CSS响应式设计
- CSS动画和过渡
- CSS性能优化
- CSS工程化工具
- CSS架构设计
- CSS变量和现代特性

### 进阶知识点（P2-P3）

- CSS组件化设计
- CSS方法论（BEM、SMACSS等）
- CSS预处理器
- CSS-in-JS
- 现代CSS技术（容器查询、子网格等）
