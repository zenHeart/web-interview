# CSS

本学科关注CSS样式语言的核心概念和应用，主题组织参考[CSS规范](https://www.w3.org/Style/CSS/)和[MDN CSS文档](https://developer.mozilla.org/zh-CN/docs/Web/CSS)。

## 主题概览

本学科包含以下主题：

1. [基础概念](./01.concept.md) - CSS核心概念和基础理论
2. [选择器和优先级](./02.selector.md) - CSS选择器系统和优先级计算
3. [盒模型和布局](./03.box-layout.md) - 盒模型、定位和基础布局
4. [Flexbox布局](./04.flexbox.md) - 弹性盒子布局系统
5. [Grid布局](./05.grid.md) - 网格布局系统
6. [响应式设计](./06.responsive.md) - 响应式布局和媒体查询
7. [动画和变换](./07.animation.md) - CSS动画、过渡和变换
8. [CSS工具链](./08.toolchain.md) - 预处理器、后处理器和工具
9. [编码实践](./09.coding.md) - 实际编码题和最佳实践

## 核心知识点

### 基础理论

- CSS层叠和继承机制
- 选择器优先级计算
- 盒模型和定位系统

### 布局技术

- 传统布局（文档流、浮动、定位）
- 现代布局（Flexbox、Grid）
- 响应式布局（媒体查询、容器查询）

### 视觉效果

- 颜色和渐变
- 阴影和边框
- 动画和变换

### 工程化

- CSS预处理器（Sass、Less）
- CSS后处理器（PostCSS）
- CSS模块化和组件化

## 面试重点

CSS在前端面试中的重点考察方向：

1. **布局能力** - Flexbox和Grid的熟练应用
2. **响应式设计** - 多设备适配能力
3. **性能优化** - CSS性能优化技巧
4. **兼容性处理** - 跨浏览器兼容性
5. **工程化思维** - CSS模块化和维护性
