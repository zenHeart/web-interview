# Flexbox布局✅

本主题涵盖CSS Flexbox（弹性盒子）布局系统，包括容器属性和项目属性的详细使用方法。

## 什么是Flexbox布局？ {#p0-flexbox-concept}

<Answer>

**Flexbox概述**

Flexbox（Flexible Box Layout）是CSS3引入的一种强大的布局方式，专门用于创建灵活的响应式布局。

### 1. Flexbox核心概念

#### 容器（Container）

- 设置 `display: flex` 或 `display: inline-flex` 的元素
- 控制其子元素的排列方式

#### 项目（Item）

- Flex容器的直接子元素
- 成为弹性项目，可以灵活调整大小和位置

#### 主轴（Main Axis）

- 项目排列的主要方向
- 由 `flex-direction` 属性决定

#### 交叉轴（Cross Axis）

- 垂直于主轴的方向
- 用于对齐项目

### 2. 基本使用

```css
/* 创建Flex容器 */
.container {
  display: flex; /* 块级弹性容器 */
  /* 或 */
  display: inline-flex; /* 行内弹性容器 */
}
```

- **差**：不了解Flexbox概念，无法使用弹性布局
- **良**：理解Flexbox基本概念，能实现简单布局

## Flexbox容器属性有哪些？ {#p0-flexbox-container}

<Answer>

**容器属性详解**

Flexbox容器属性控制项目的排列方式和对齐方式。

### 1. flex-direction（主轴方向）

控制项目在主轴上的排列方向：

```css
.container {
  flex-direction: row; /* 默认值：水平从左到右 */
  flex-direction: row-reverse; /* 水平从右到左 */
  flex-direction: column; /* 垂直从上到下 */
  flex-direction: column-reverse; /* 垂直从下到上 */
}
```

### 2. flex-wrap（换行）

控制项目是否换行：

```css
.container {
  flex-wrap: nowrap; /* 默认值：不换行 */
  flex-wrap: wrap; /* 换行，第一行在上方 */
  flex-wrap: wrap-reverse; /* 换行，第一行在下方 */
}
```

### 3. flex-flow（简写属性）

`flex-direction` 和 `flex-wrap` 的简写：

```css
.container {
  flex-flow: row wrap; /* 水平排列，允许换行 */
  flex-flow: column nowrap; /* 垂直排列，不换行 */
}
```

### 4. justify-content（主轴对齐）

控制项目在主轴上的对齐方式：

```css
.container {
  justify-content: flex-start; /* 默认值：起点对齐 */
  justify-content: flex-end; /* 终点对齐 */
  justify-content: center; /* 居中对齐 */
  justify-content: space-between; /* 两端对齐，项目间间隔相等 */
  justify-content: space-around; /* 项目两侧间隔相等 */
  justify-content: space-evenly; /* 所有间隔相等 */
}
```

### 5. align-items（交叉轴对齐）

控制项目在交叉轴上的对齐方式：

```css
.container {
  align-items: stretch; /* 默认值：拉伸填满容器 */
  align-items: flex-start; /* 起点对齐 */
  align-items: flex-end; /* 终点对齐 */
  align-items: center; /* 居中对齐 */
  align-items: baseline; /* 基线对齐 */
}
```

### 6. align-content（多行对齐）

控制多行项目在交叉轴上的对齐方式：

```css
.container {
  align-content: stretch; /* 默认值：拉伸填满容器 */
  align-content: flex-start; /* 起点对齐 */
  align-content: flex-end; /* 终点对齐 */
  align-content: center; /* 居中对齐 */
  align-content: space-between; /* 两端对齐 */
  align-content: space-around; /* 项目两侧间隔相等 */
}
```

**实际应用示例**

```css
/* 导航栏布局 */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

/* 卡片网格 */
.card-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

/* 垂直居中 */
.centered {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
```

**面试官视角**

- **差**：只知道display: flex，不了解容器属性
- **良**：掌握常用容器属性，能实现基本布局
- **优**：深入理解所有容器属性，能灵活组合实现复杂布局

## Flexbox项目属性有哪些？ {#p0-flexbox-items}

<Answer>

**项目属性详解**

Flexbox项目属性控制单个项目的行为和排列。

### 1. order（排序）

控制项目的排列顺序，数值越小越靠前：

```css
.item {
  order: 0; /* 默认值 */
  order: 1; /* 排在后面 */
  order: -1; /* 排在前面 */
}
```

### 2. flex-grow（放大比例）

控制项目在容器中的放大比例：

```css
.item {
  flex-grow: 0; /* 默认值：不放大 */
  flex-grow: 1; /* 放大1倍 */
  flex-grow: 2; /* 放大2倍 */
}
```

### 3. flex-shrink（缩小比例）

控制项目在容器中的缩小比例：

```css
.item {
  flex-shrink: 1; /* 默认值：可以缩小 */
  flex-shrink: 0; /* 不缩小 */
  flex-shrink: 2; /* 缩小2倍 */
}
```

### 4. flex-basis（基础大小）

设置项目的基础大小：

```css
.item {
  flex-basis: auto; /* 默认值：基于内容 */
  flex-basis: 200px; /* 固定宽度 */
  flex-basis: 50%; /* 百分比 */
}
```

### 5. flex（简写属性）

`flex-grow`、`flex-shrink`、`flex-basis` 的简写：

```css
.item {
  flex: 0 1 auto; /* 默认值 */
  flex: 1; /* 等价于 flex: 1 1 0% */
  flex: 1 1 auto; /* 可放大可缩小 */
  flex: 0 0 200px; /* 固定大小，不放大不缩小 */
}
```

### 6. align-self（自身对齐）

覆盖容器的 `align-items` 设置：

```css
.item {
  align-self: auto; /* 默认值：继承父容器 */
  align-self: flex-start; /* 起点对齐 */
  align-self: center; /* 居中对齐 */
  align-self: flex-end; /* 终点对齐 */
  align-self: stretch; /* 拉伸填满 */
}
```

**实际应用示例**

```css
/* 响应式侧边栏 */
.sidebar {
  flex: 0 0 250px; /* 固定宽度，不放大不缩小 */
}

.main-content {
  flex: 1; /* 占据剩余空间 */
}

/* 导航菜单 */
.nav-item {
  flex: 1; /* 等宽分布 */
}

.nav-item.active {
  flex: 2; /* 活跃项目占据更多空间 */
}

/* 卡片布局 */
.card {
  flex: 1 1 300px; /* 基础300px，可放大可缩小 */
}
```

### 7. 常用flex值

```css
/* 常用组合 */
.flex-none { flex: none; } /* 0 0 auto */
.flex-auto { flex: auto; } /* 1 1 auto */
.flex-1 { flex: 1; } /* 1 1 0% */
.flex-initial { flex: initial; } /* 0 1 auto */
```

**面试官视角**

- **差**：不了解项目属性，无法控制单个项目行为
- **良**：掌握常用项目属性，能实现基本项目控制
- **优**：深入理解所有项目属性，能精确控制项目布局

## 如何使用Flexbox实现常见布局？ {#p1-flexbox-layouts}

<Answer>

**常见布局实现**

Flexbox可以轻松实现各种常见布局模式。

### 1. 水平居中

```css
/* 水平居中单个元素 */
.centered {
  display: flex;
  justify-content: center;
}

/* 水平居中多个元素 */
.container {
  display: flex;
  justify-content: center;
  gap: 20px;
}
```

### 2. 垂直居中

```css
/* 垂直居中 */
.centered {
  display: flex;
  align-items: center;
  min-height: 100vh;
}

/* 完全居中 */
.centered {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
```

### 3. 导航栏布局

```css
/* 基础导航栏 */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 0 20px;
}

/* 响应式导航栏 */
.navbar {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

@media (max-width: 768px) {
  .navbar {
    flex-direction: column;
  }
}
```

### 4. 卡片网格

```css
/* 自适应卡片网格 */
.card-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.card {
  flex: 1 1 300px; /* 基础300px，可放大可缩小 */
  min-width: 250px;
}
```

### 5. 侧边栏布局

```css
/* 固定侧边栏 */
.layout {
  display: flex;
  min-height: 100vh;
}

.sidebar {
  flex: 0 0 250px; /* 固定宽度 */
  background: #f5f5f5;
}

.main-content {
  flex: 1; /* 占据剩余空间 */
}
```

### 6. 表单布局

```css
/* 表单行 */
.form-row {
  display: flex;
  gap: 10px;
  margin-bottom: 15px;
}

.form-label {
  flex: 0 0 120px; /* 固定宽度 */
}

.form-input {
  flex: 1; /* 占据剩余空间 */
}
```

### 7. 响应式布局

```css
/* 响应式容器 */
.responsive-container {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.responsive-item {
  flex: 1 1 300px;
}

/* 移动端优化 */
@media (max-width: 768px) {
  .responsive-item {
    flex: 1 1 100%;
  }
}
```

### 8. 等高布局

```css
/* 等高卡片 */
.card-container {
  display: flex;
  gap: 20px;
}

.card {
  flex: 1;
  display: flex;
  flex-direction: column;
}

.card-content {
  flex: 1; /* 占据剩余空间，实现等高 */
}
```

- **差**：无法使用Flexbox实现基本布局
- **良**：能实现常见布局，了解响应式设计
- **优**：熟练运用Flexbox解决复杂布局问题，考虑性能和兼容性
