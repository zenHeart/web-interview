4. 文档流特点说明
  • 块级元素：独占一行，可设置宽高，宽度默认100%
  • 内联元素：在同一行显示，不能设置宽高，宽度由内容决定
  • inline-block：结合两者优点，可水平排列且能设置宽高
  • 默认顺序：元素按HTML结构从上到下、从左到右排列
