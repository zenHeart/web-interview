响应式布局特点：

  • 使用媒体查询(@media)适配不同屏幕
  • 流式布局和弹性单位(%, vw, vh)
  • 灵活的网格系统
  • 图片和媒体内容自适应
  • 移动优先的设计理念

常见断点：

  • 手机：≤ 768px
  • 平板：769px - 1024px
  • 桌面：≥ 1025px
