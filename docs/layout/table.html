表格布局特点：

  • 使用 display: table 系列属性
  • 自动等高列布局
  • 容易实现垂直居中
  • 单元格宽度自动分配
  • 适合数据展示和等高布局

注意：现代布局推荐使用 Flexbox 或 Grid， 表格布局主要用于特定场景或兼容老版本浏览器。
