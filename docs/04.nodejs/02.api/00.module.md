# 模块系统

## CommonJS 与 ESM 模块系统区别？ {#p0-modules}

<Answer>

|系统|CommonJS(CJS)|ESM|
|:--|:--|:--|
|加载|同步 require|异步，支持顶层 await|
|导出语义|导出为对象快照（非 live binding）|live binding，静态可分析（利于 tree-shaking）|
|解析与定位|传统解析，可省扩展名，支持目录 index|URL/显式扩展名；受 exports/imports 影响|
|互操作|可 require JSON、.node；用 import() 加载 ESM|CJS 需用动态 import；ESM 不可直接用 require|
|文件/配置|.cjs 或 package.json 设置 "type":"commonjs"|.mjs 或 package.json 设置 "type":"module"|
|实现|本质上是一个必包函数，默认非严格模式|V8 引擎内置支持，默认严格模式|

**示例说明**

```js
// package.json
{ "type": "module", "exports": "./dist/index.js" }

// CJS 中加载 ESM（需异步）
/* index.cjs */
(async () => {
  const { sum } = await import('./esm.mjs')
  console.log(sum(1, 2))
})()

/* esm.mjs */
export const sum = (a, b) => a + b
const cfg = await import('./cfg.json', { assert: { type: 'json' } })
console.log(cfg.default.name)
```

:::tip
ESM 需写全扩展名，路径以 ./ 或 ../ 开头；库发布优先使用 package.json 的 exports 控制入口，避免隐式深引用与解析歧义。
:::

* [Node.js ESM](https://nodejs.org/api/esm.html) ESM

</Answer>

## ESM 支持顶层异步，为什么 Node.js 中可以加载 ESM 模块? {#p0-cjs-require-esm}

<Answer>

Node.js  Common.js 模块只支持引入没有顶层异步的 ESM 模块， 如果存在异步会抛出 [ERR_REQUIRE_ASYNC_MODULE](https://github.com/nodejs/node/blob/91f035e5975ad871977f3395664d3162444b3194/lib/internal/modules/esm/module_job.js#L503C17-L503C41) 错误，如果希望在在 Common.js 中引用异步可采用 `import` 语句，运行时需要开启 `--experimental-print-required-tla` 配置。

```js
import('./asyncAdd.mjs').then(({ add }) => {
  console.log(add(1, 2)) // 3
})
```

* [实现同步 ESM 的讨论](https://github.com/nodejs/node/pull/51977)

</Answer>
