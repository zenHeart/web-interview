## 题库

### P0 必考知识点

#### 京东自研 Taro 跨端编译原理与运行时框架核心机制？ {#p0-taro-cross-platform}

<Answer>

### 核心结论

Taro 经历从 Taro 1/2（纯编译时 AST 静态代码转译）到 **Taro 3（重运行时架构）** 的重大演进。Taro 3 的核心是在小程序逻辑层（JSCore）**模拟实现了一套精简的 DOM/BOM API 与事件系统**，使标准 React/Vue 渲染器直接感知为浏览器环境，从而无缝运行几乎所有 Web 生态。

---

### Taro 3 运行时核心流转

1. **精简 DOM 树构建（taro-runtime）**：
   - 在小程序逻辑层模拟 `TaroElement` 与 `TaroDocument`。React/Vue 组件挂载时，生成的并不是真实浏览器 DOM，而是一棵纯 JS 描述的虚拟节点树。
2. **数据收集与批量变更通知**：
   - 收集一次 Tick 内所有节点的增删改变动，打包为序列化的 JSON 数据对象。
3. **小程序模板递归渲染（Template Recursion）**：
   - 通过基础 WXML 模板（`template name="taro_tmpl"`）按节点类型递归展开渲染，将逻辑层计算的虚拟 DOM 树映射为小程序的原生视图标签。

---

### 面试官视角

考查候选人对前端编译器原理、AST 转译以及现代跨端运行时虚拟 DOM 适配的深层认知。

#### 电商大促秒杀会场（亿级流量）前端防刷与稳定性保障策略？ {#p0-ecommerce-seckill-stability}

<Answer>

### 核心结论

面对 618 零点脉冲式海量并发冲击，前端绝不能将所有未经过滤的请求直接穿透到后端。必须在前端构建**“层层截流、动静分离、本地答题防刷、柔性降级”**的多层防御防线。

---

### 关键防线设计

1. **动静完全分离与 CDN 边缘预热**：
   - 会场静态骨架、HTML、CSS、JS 与商品基础图片 100% 部署至边缘 CDN，大促前全面预热，源站零静态请求压力。
2. **按钮控制与前端限频防连击**：
   - 点击秒杀后，按钮立即置灰并进入倒计时锁死（如 3 秒内禁用），展示“排队中”动效。
3. **滑块验证码与人机校验（客户端风控防刷）**：
   - 接入设备指纹 SDK，在点击秒杀前识别自动化脚本与模拟器行为，高风险请求弹窗验证码拦截。
4. **服务端限流与柔性降级（排队机制）**：
   - 秒杀接口返回 `429 Too Many Requests` 或特定错误码时，前端友好提示“服务器挤爆了，请稍后再试”，坚决杜绝前端无脑轮询重试。
