原生 JavaScript 数组操作：在指定位置插入/删除/替换元素的底层机制（splice）？​

答案

核心结论​

在 JavaScript 数组操作中，Array.prototype.splice() 是最核心的原地修改（In-place Mutation）方法，支持在任意索引位置执行删除、插入和替换。它会改变原数组并返回包含被删除元素的数组。

原理解析与核心语法​

array.splice(startIndex, deleteCount, ...itemsToAdd)
  1. 删除元素： 
    const arr = [1, 2, 3, 4]
    // 从索引 1 开始删除 2 个元素
    const removed = arr.splice(1, 2)
    console.log(arr)     // [1, 4]
    console.log(removed) // [2, 3]
  2. 在中间插入元素（deleteCount = 0）： 
    const arr = [1, 2, 3, 4]
    // 在索引 2 处插入 'a', 'b'
    arr.splice(2, 0, 'a', 'b')
    console.log(arr) // [1, 2, 'a', 'b', 3, 4]
  3. 替换元素： 
    const arr = [1, 2, 3, 4]
    // 将索引 1 处的元素替换为 99
    arr.splice(1, 1, 99)
    console.log(arr) // [1, 99, 3, 4]

splice vs slice 对比​

  • splice：修改原数组（Mutating），参数是 (start, deleteCount, ...items)，复杂度 $O(N)$（需内存移动后续元素）。
  • slice：不修改原数组（Pure），返回浅拷贝新数组，参数是 (start, end)。

面试官视角​

外包技术面试非常重视语言基本功，常考察边界索引传参（如负数索引 splice(-1, 1)）、原地变异与纯函数的区别，以及现代 ES2023 新增的非变异方法 toSpliced()。

CSS BEM 命名规范及其在大型企业级项目中的价值？​

答案

核心结论​

BEM（Block__Element--Modifier）是一种主流的 CSS 类名命名架构思想，旨在解决大型团队开发中全局命名冲突、样式层叠权重失控、代码复用性差及维护成本高的痛点。

结构规范与示例​

/* 块 Block：独立有意义的实体容器 */
.btn {}

/* 元素 Element：属于 Block 的子构件，不可脱离 Block 单独存在，用双下划线 __ 拼接 */
.btn__icon {}
.btn__text {}

/* 修饰符 Modifier：Block 或 Element 的状态/样式外观变化，用双中划线 -- 拼接 */
.btn--primary {}
.btn--disabled {}
.btn__icon--large {}

核心优势​

  1. 扁平化选择器权重：全部使用类选择器（Class），避免多层嵌套（如 .header .nav ul li a），选择器权重恒定，易于覆盖。
  2. 自描述性文档化：仅看 HTML 类名即可清晰知晓组件层级与状态关联。
  3. 无缝契合组件化：极易与 Vue/React 的单文件组件样式封装相结合。

延伸阅读​

  • BEM 官方规范与最佳实践
  • CSS 架构设计与组织原则

考察重点速览​

  • 必考知识点: HTML5/CSS3 基础特性、JavaScript 数组常用 API（splice/slice/map/reduce）、Vue 基础（组件通信/生命周期）。
  • 高频面试题: 数组原地操作、BEM 命名、闭包场景与内存泄漏排查、与甲方客户协作敏捷沟通。
  • 编程挑战: 数组去重与扁平化、简单手写 Promise、DOM 事件操作。

备考建议​

针对性准备策略

  • 突出基础扎实与即战力: 外包驻场要求员工入项即能上手开发，重点展现对常用组件库（Element UI/Ant Design）熟练度与常见 CRUD 业务开发速度。
  • 注重甲方沟通与配合度: 表现出抗压能力强、服从项目组工作安排、保密意识与规范意识健全的职业素养。

推荐准备资源

  • MDN JavaScript 权威教程
  • Vue 官方开发文档

差异化准备建议

  • 校招生: 基础扎实，能快速通过笔试与基础编程题即可。
  • 社招生: 准备 2-3 个完整的端到端项目交付经验，重点突出独立负责模块、解决线上缺陷及客户满意度。
